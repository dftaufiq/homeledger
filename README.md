HomeLedger — a working household budget site for the fictional Alvarez family, November 2026: a dashboard, a searchable transaction ledger, editable budgets, bills and subscriptions, savings goals, and three money calculators (50/30/20 planner, debt payoff, savings goal). Every figure is computed from one set of 56 transactions — income $6,850, spent $4,674, saved $2,176 (31.8%). Static files only, no build step, no network.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — Dashboard, Transactions, Budgets, Bills &amp; Subscriptions, Goals and Tools are all hash routes in the top nav.
